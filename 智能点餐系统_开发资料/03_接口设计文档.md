> 基于 xshell 内部培训资料整理

---

## 一、接口总览

| 接口 | 方法 | 路径 | 用途 |
|------|------|------|------|
| 智能推荐 | POST | `/api/v1/recommend` | 核心接口：上传图片/文字，获取推荐结果 |
| 食物识别 | POST | `/api/v1/recognize` | 单独调用：识别食物图片 |
| 口味分析 | POST | `/api/v1/analyze_taste` | 单独调用：分析食物口味 |
| 附近餐厅 | GET | `/api/v1/nearby_restaurants` | 查询附近餐厅 |
| 用户画像 | GET | `/api/v1/user_profile` | 查询用户偏好 |
| 健康检查 | GET | `/health` | 服务健康检查 |

## 二、详细接口设计

---

### 接口 1：智能推荐（主接口）

**请求**
```
POST /api/v1/recommend
Content-Type: multipart/form-data
```

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| image | file | 否 | 食物图片（与 text 二选一） |
| text | string | 否 | 文字描述（与 image 二选一） |
| user_id | string | 是 | 用户ID |
| longitude | float | 是 | 用户经度 |
| latitude | float | 是 | 用户纬度 |
| distance | int | 否 | 搜索半径，默认3000米 |

**请求示例**
```json
// 方式1：上传图片
{
  "user_id": "user_1001",
  "longitude": 116.4074,
  "latitude": 39.9042,
  "distance": 3000
}
// + 图片文件

// 方式2：文字描述
{
  "user_id": "user_1001",
  "text": "我想吃辣的川菜",
  "longitude": 116.4074,
  "latitude": 39.9042
}
```

**响应**
```json
{
  "code": 0,
  "message": "success",
  "data": {
    "food_name": "宫保鸡丁",
    "recommendations": [
      {
        "rank": 1,
        "restaurant_name": "川味坊",
        "restaurant_id": "r_001",
        "distance": "800米",
        "queue_people": 3,
        "rating": 4.5,
        "dish_name": "宫保鸡丁",
        "dish_price": 38.0,
        "reason": "距离最近且排队人数少，口味与您的历史偏好高度匹配（辣+川菜）"
      },
      {
        "rank": 2,
        "restaurant_name": "蜀香楼",
        "restaurant_id": "r_002",
        "distance": "1200米",
        "queue_people": 0,
        "rating": 4.7,
        "dish_name": "宫保鸡丁",
        "dish_price": 42.0,
        "reason": "评分最高，无需排队，适合立即用餐"
      }
    ]
  }
}
```

**错误码**
| code | 说明 |
|------|------|
| 0 | 成功 |
| 4001 | 缺少输入（图片和文字都没有） |
| 4002 | 用户不存在 |
| 5001 | 食物识别失败 |
| 5002 | 餐厅查询失败 |
| 5003 | LLM生成失败 |

## 三、数据模型定义（Pydantic）

### 请求模型

```python
# api/models.py

from pydantic import BaseModel, Field
from typing import Optional

class RecommendRequest(BaseModel):
    """推荐接口请求"""
    user_id: str = Field(..., description="用户ID")
    text: Optional[str] = Field(None, description="文字描述（与图片二选一）")
    longitude: float = Field(..., description="经度")
    latitude: float = Field(..., description="纬度")
    distance: int = Field(3000, description="搜索半径（米）")

class AnalyzeTasteRequest(BaseModel):
    """口味分析请求"""
    food_name: str = Field(..., description="食物名称")

class NearbyRestaurantsRequest(BaseModel):
    """附近餐厅查询请求"""
    longitude: float
    latitude: float
    distance: int = 3000
    limit: int = 10
```

### 响应模型

```python
# api/models.py

from pydantic import BaseModel
from typing import Optional, List

class FoodCandidate(BaseModel):
    name: str
    confidence: float

class TasteInfo(BaseModel):
    food_name: str
    cuisine: str
    spicy_level: int
    main_taste: List[str]
    flavor_tags: List[str]
    suitable_scenes: List[str]

class RestaurantInfo(BaseModel):
    restaurant_id: str
    name: str
    address: str
    longitude: float
    latitude: float
    distance: int
    rating: float
    queue_people: int
    avg_price: float
    tags: List[str]

class RecommendationItem(BaseModel):
    rank: int
    restaurant_name: str
    restaurant_id: str
    distance: str
    queue_people: int
    rating: float
    dish_name: str
    dish_price: float
    reason: str

class RecommendResponse(BaseModel):
    food_name: str
    recommendations: List[RecommendationItem]

class ApiResponse(BaseModel):
    """统一响应格式"""
    code: int
    message: str
    data: Optional[dict] = None
```

## 四、统一响应格式

所有接口统一使用以下响应格式：

```json
{
  "code": 0,
  "message": "success",
  "data": { ... }
}
```

| code | 含义 |
|------|------|
| 0 | 成功 |
| 4001-4999 | 客户端错误（参数错误、缺少必填等） |
| 5001-5999 | 服务端错误（外部服务调用失败等） |

## 五、Python 调用示例

```python
import requests

# 智能推荐（图片）
response = requests.post(
    "http://localhost:8000/api/v1/recommend",
    data={
        "user_id": "user_1001",
        "longitude": 116.4074,
        "latitude": 39.9042,
    },
    files={"image": open("food.jpg", "rb")}
)
print(response.json())

# 口味分析
response = requests.post(
    "http://localhost:8000/api/v1/analyze_taste",
    json={"food_name": "宫保鸡丁"}
)
print(response.json())

# 附近餐厅
response = requests.get(
    "http://localhost:8000/api/v1/nearby_restaurants",
    params={
        "longitude": 116.4074,
        "latitude": 39.9042,
        "distance": 3000
    }
)
print(response.json())
```
